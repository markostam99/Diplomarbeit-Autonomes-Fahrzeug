# Softwaremodultests

Dieser Ordner dokumentiert die Funktionstests der einzelnen Softwaremodule aus `src/`.

Die Module wurden während der Softwareentwicklung einzeln getestet, bevor sie in die Gesamtsteuerung des Fahrzeugs integriert wurden.

## Getestete Module

- Motorsteuerung
- Ultraschallsensoren
- Status-LEDs
- Starttaster
- Kamera

Die Testprogramme dienen der Überprüfung der grundlegenden Funktion und der korrekten Anbindung der jeweiligen Module.
