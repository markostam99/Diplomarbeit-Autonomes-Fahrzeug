## Test der 90°-Kurvenfahrt

In diesem Ordner wird die praktische Erprobung der 90°-Kurven dokumentiert. Nach dem Austausch des ursprünglichen Stützrades durch einen Ball Caster wurden die Kurvenparameter erneut bestimmt.

## Ermittelte Parameter

| Kurve | PWM links | PWM rechts | Dauer |
|---|---:|---:|---:|
| Linkskurve | 10 % | 73 % | 1,0 s |
| Rechtskurve | 73 % | 10 % | 1,0 s |

Die neuen Parameter ermöglichen eine gleichmässige 90°-Kurvenfahrt. Durch den Ball Caster konnte zudem das zuvor auftretende Problem beim Übergang von der Kurvenfahrt zur Geradeausfahrt behoben werden.
