## Test der 90°-Kurvenfahrt

Das folgende Video zeigt die praktische Erprobung der Kurvenfahrt auf der Teststrecke. Ziel des Tests war es, geeignete PWM-Werte und eine passende Kurvendauer für eine möglichst reproduzierbare 90°-Kurve zu bestimmen.

Für die Linkskurve wurden 20 % PWM am linken und 70 % PWM am rechten Motor verwendet. Für die Rechtskurve wurden die Werte entsprechend vertauscht. Mit einer Kurvendauer von 0,8 Sekunden konnten in beiden Richtungen gleichmässige und annähernd 90° grosse Kurven erreicht werden.

Die ermittelten Parameter dienen später als Grundlage für die automatische Kurvenfahrt nach Erkennung einer Kurvenmarkierung.
