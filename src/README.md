# Fahrzeugsoftware

Dieser Ordner enthält den Quellcode für die eigentliche Steuerungssoftware des autonomen Fahrzeugs.

Die Software wird modular aufgebaut. Die einzelnen Module übernehmen klar definierte Aufgaben wie Motorsteuerung, Abstandserfassung, Bildverarbeitung und Fahrzeuglogik. Die Funktionen werden schrittweise entwickelt, getestet und anschliessend zur vollständigen Fahrzeugsteuerung zusammengeführt.
