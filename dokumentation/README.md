# Dokumentation

Dieser Ordner dient der strukturierten Ablage technischer Unterlagen, die während der praktischen Umsetzung und Weiterentwicklung des autonomen Fahrzeugs entstehen.

Die Inhalte werden im Verlauf des Projekts fortlaufend ergänzt und dienen dazu, wichtige technische Informationen und Entwicklungsstände übersichtlich und nachvollziehbar festzuhalten.
