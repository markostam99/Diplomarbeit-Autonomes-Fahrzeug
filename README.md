# HF Diplomarbeit – Autonomes Robotikfahrzeug

## Projektbeschreibung

Entwicklung eines autonomen Robotikfahrzeugs auf Basis eines Raspberry Pi 4.

## Hardware

- Raspberry Pi 4
- Raspberry Pi Camera Module 3 Wide
- Grove Ultrasonic Ranger
- TB6612FNG Motortreiber
- Robot05 Chassis

## Ziel

Der Roboter soll eine Teststrecke selbstständig befahren, blaue und orange Linien erkennen sowie später Hindernisse identifizieren und darauf reagieren.
